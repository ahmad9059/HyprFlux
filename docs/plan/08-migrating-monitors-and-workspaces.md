# 08 — Migrating Monitors and Workspaces (`hl.monitor`, `hl.workspace_rule`)

## 8.1 `hl.monitor` — full field list

```lua
hl.monitor({
    output = "eDP-1",          -- required; "" = fallback rule; "desc:..." = description match
    mode = "2560x1440@165",    -- "preferred" | "highres" | "highrr" | "maxwidth" | "modeline ..."
    position = "0x0",          -- "auto", "auto-right", "auto-center-right", ...
    scale = 1.0,               -- float, or "auto" (PPI-based)
    disabled = false,
    transform = 0,             -- 0..7 rotation/flip
    mirror = "",               -- output to mirror
    bitdepth = 8,              -- 8 or 10
    cm = "srgb",               -- color management preset
    sdr_eotf = "default",      -- "default" | "gamma22" | "srgb"
    sdrbrightness = 1.0,
    sdrsaturation = 1.0,
    vrr = 0,                   -- per-display VRR
    icc = "",                  -- absolute path to ICC profile
    reserved_area = { top = 0, bottom = 0, left = 0, right = 0 },  -- or int
    supports_wide_color = 0, supports_hdr = 0,
    sdr_min_luminance = 0.2, sdr_max_luminance = 80,
    min_luminance = -1, max_luminance = -1, max_avg_luminance = -1,
})
```

Only `output` is required; everything else defaults sensibly. Multiple `hl.monitor()` calls for
multiple monitors; each is one rule.

HyprFlux examples:

```lua
-- hyprlang:  monitor = , preferred, auto, 1          (fallback)
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })

-- hyprlang:  monitor = eDP-1, 2560x1440@165, 0x0, 1
hl.monitor({ output = "eDP-1", mode = "2560x1440@165", position = "0x0", scale = 1.0 })

-- hyprlang:  monitor = HDMI-A-1, 1920x1080, auto, 1, transform, 1
hl.monitor({ output = "HDMI-A-1", mode = "1920x1080", position = "auto", scale = 1, transform = 1 })
```

## 8.2 nwg-displays — already Lua-aware

nwg-displays ≥ 2.4 writes **both** `monitors.conf` and `monitors.lua` (your live
`~/.config/hypr/monitors.lua` is exactly this):

```lua
-- Generated by nwg-displays on 2026-08-03 at 20:47:03. Do not edit manually.
hl.monitor({
    output = "eDP-1",
    mode = "2560x1440@165.0",
    position = "0x0",
    scale = 1.0
})
```

Official nwg-displays README (Lua mode): in `hyprland.lua` use `require("monitors")` (and
`require("workspaces")` for the workspace rules file), instead of the old
`source = ~/.config/hypr/monitors.conf`. Caveat: **do not set `misc.disable_autoreload = true`**
or you must reload Hyprland manually after nwg-displays applies changes.

> HyprFlux note: `monitors.conf` currently lives at the end of `hyprland.conf`'s source list.
> In Lua mode, `require("monitors")` goes into `hyprland.lua`. `Monitor_Profiles/` backups will
> become `.lua` files too (see doc 15 §5).

## 8.3 `hl.workspace_rule`

```lua
hl.workspace_rule({ workspace = "3", no_rounding = true, decorate = false })
hl.workspace_rule({ workspace = "name:coding", gaps_in = 0, gaps_out = 0, no_border = true, monitor = "DP-1" })
hl.workspace_rule({ workspace = "name:gaming", monitor = "desc:Chimei Innolux Corporation 0x150C", default = true })
hl.workspace_rule({ workspace = "5", on_created_empty = "firefox" })
hl.workspace_rule({ workspace = "special:scratchpad", on_created_empty = "foot" })
hl.workspace_rule({ workspace = "15", animation = "slidevert", default_name = "slider" })
hl.workspace_rule({ workspace = "2", layout = "scrolling" })
hl.workspace_rule({ workspace = "8", border_size = 8 })
```

All rule fields:

| field | type | meaning |
|---|---|---|
| `workspace` | str (required) | id, `name:...`, `special:...`, or workspace selector |
| `monitor` | str | bind to monitor |
| `default` | bool | default workspace for that monitor |
| `gaps_in` / `gaps_out` / `float_gaps` | css_gaps | override gaps |
| `border_size` | int | override border |
| `no_border` / `no_shadow` / `no_rounding` / `decorate` | bool | per-workspace decorations |
| `persistent` | bool | keep workspace alive when empty |
| `on_created_empty` | str | command when created empty |
| `default_name` | str | name for the workspace |
| `layout` | str | per-workspace layout |
| `animation` | str | animation style for the workspace |
| `layout_opts` | table | layout-specific options |

**Smart gaps** (useful for HyprFlux's aesthetic):

```lua
hl.workspace_rule({ workspace = "w[tv1]", gaps_out = 0, gaps_in = 0 })
hl.workspace_rule({ workspace = "f[1]",  gaps_out = 0, gaps_in = 0 })
hl.window_rule({ match = { float = false, workspace = "w[tv1]" }, border_size = 0, rounding = 0 })
```

## 8.4 Workspace selectors (unchanged from hyprlang)

```
1 | +1 | -3            ID / relative ID
m+1 | m~3 | r+1        monitor-relative (r = includes empty workspaces)
e+1                    open-workspace-relative
name:Web               named
previous | previous_per_monitor
empty | emptyn | emptym
special | special:name
```

## 8.5 HyprFlux `workspaces.conf` / `WorkSpaceRules`

`workspaces.conf` is nwg-displays-managed (currently comments only) — it converts to
`workspaces.lua` the same way `monitors.lua` does. `UserConfigs/WorkSpaceRules` is a **guide only
(not sourced)**; it becomes `UserConfigs/workspace-rules.lua` with the same example rules
converted to `hl.workspace_rule` — still not required by default unless you want smart gaps.

## 8.6 Monitor hotplug & profiles

- `Monitor_Profiles/*.conf` → `Monitor_Profiles/*.lua` (module files that just call
  `hl.monitor(...)`; profile switcher scripts `MonitorProfiles.sh` must be updated to install
  the `.lua` variant — see doc 15 §5).
- `LaptopDisplay.conf` (eDP-1 lid flow) converts to a tiny `hl.monitor` line in `laptops.lua`.
