# Power menu (wlogout)

Open it with **CTRL+ALT+P**, the Waybar power button, or the notification-panel
power button. Press the shortcut again, or **Esc**, to close it.

## Design

- Square cards sized to the focused monitor and shown on that monitor. Sizes use
  logical pixels, so scaled and rotated displays work.
- Same look as the notification panel: accent border, rounded corners, Adwaita
  Sans, colors from `hyprflux-colors.conf` (via `utilities/sync-colors.sh`).
- Hover fills the card. Actions that end the session or power the machine off
  (Logout, Reboot, Shutdown) turn red. The focus ring marks the keyboard target.
- The key for each action is shown on its card. Keys are unchanged:
  `l` Lock, `e` Logout, `u` Suspend, `h` Hibernate, `r` Reboot, `s` Shutdown.
- Order: Lock, Logout, Suspend, Hibernate, Reboot, Shutdown. Destructive actions
  are last and furthest from the default focus.
- A layer rule (`logout_dialog`) blurs what is behind the menu.

## Hibernate

Hibernate needs a resume device in the boot image. Without one the machine would
power off, boot fresh, and discard the open session. The menu therefore hides
Hibernate until `resume=` is on the kernel command line and logind permits it.
Suspend is also hidden when logind reports it unavailable. `SleepAction.sh`
checks these capabilities before starting either action; `Hibernate.sh` delegates
to it. The sleep key prefers supported Suspend, otherwise Hibernate.

`HYPRFLUX_ALLOW_HIBERNATE=1` bypasses only the `resume=` requirement, for setups
using systemd's `HibernateLocation` EFI variable. It never overrides system policy
or `noresume`. Capability query failures refuse the operation.

### Enabling it (busybox mkinitcpio, UEFI)

1. Find the swap partition's UUID: `sudo blkid -s UUID -o value /dev/<swap>`.
   zram cannot be used; it needs a real swap partition or file at least as large
   as the memory in use.
2. Add `resume` after `filesystems` in `HOOKS` in `/etc/mkinitcpio.conf`.
3. Append `resume=UUID=<uuid>` to the kernel command line. For a unified kernel
   image that is `/etc/kernel/cmdline`; for GRUB it is `GRUB_CMDLINE_LINUX` plus
   `grub-mkconfig`.
4. Rebuild: `sudo mkinitcpio -P`. For a unified kernel image keep the previous
   image until the new one has booted, and do this while no package update is
   running.
5. Reboot, save your work, and hibernate once to test. Resume is only proven by
   waking from it.

Kernel lockdown (Secure Boot with lockdown) disables hibernation. On hybrid
NVIDIA laptops require driver-version-specific setup; do not blindly enable
legacy NVIDIA sleep services with drivers using kernel suspend notifiers.
See `LID-AND-SLEEP-2026-11-08.md` for this machine's verified manual hibernation
and the separate, still-pending lid-cycle test.

## Tests

`tests/test_wlogout.py` covers layout order and keys, icons and CSS (including a
real GTK3 parse), theme color definitions, the blur rule, mirror parity, and
the launcher's geometry, rotation, monitor choice, and Hibernate filtering. No
test powers anything off. Needs `jq`; the GTK3 test needs `gtk3`.
